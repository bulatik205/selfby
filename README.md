## Что такое SelfBy?

**SelfBy** - это платформа, где вы можете:
- Писать работы в Markdown
- Организовывать их в проекты
- Делиться с друзьями
- Отслеживать статистику

---

## 💕 Как начать

### Шаг 1: Регистрация
1. Нажмите "Начать бесплатно"
2. Заполните форму
3. Подтвердите аккаунт

### Шаг 2: Создайте проект
1. Перейдите в [Dashboard](https://selfby.ru/dashboard)
2. Нажмите **Новый проект**
3. Выберите название и тип

### Шаг 3: Напишите работу
1. Откройте проект
2. Нажмите **Новая работа**
3. Пишите в Markdown

### Шаг 4: Поделитесь
- Отправьте ссылку друзьям
- Или опубликуйте для всех
